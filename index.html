STAR stories

S = Situation (the context) · T = Task (my job) · A = Action (what I did, past simple: I built, I used) · R = Result (numbers if possible). End with the link to PK/PD.

Servier · Biostatistics intern

Saclay, FranceMay to September 2026Stan · R Shiny · Bayesian
S
Situation

Servier develops cancer drugs. Before a Phase III trial, the team needs one number: the probability of success. The data is small and very different from study to study.

T
Task

My task was to build a model. The model combines all past evidence. It also shows the uncertainty.

A
Action
  • I built a hierarchical Bayesian model in Stan.
  • I used a MAP prior. It borrows information from past trials.
  • I used a mixture prior for the treatment effect: one optimistic part and one sceptical part.
  • I added a commensurability matrix. It says how similar each past study is to the new one.
  • I checked the convergence and I ran sensitivity analyses.
  • I built an R Shiny application for the team.
R
Result

I delivered a decision tool with 110 unit tests. I presented the method to the team and at a biostatistics conference.

Link to PK/PD: PK/PD also uses hierarchical models, priors and simulations. I already know this way of thinking.
30-second version: At Servier, I built a Bayesian model. It predicts the success of a future trial. I combined past studies, I showed the uncertainty, and I built an app for the team.

Centre MURAZ · Statistical analyst

Burkina FasoAugust 2023 to April 2024R · mixed models · Shiny
S
Situation

Burkina Faso has a lot of malaria. A programme trained community health workers in villages. The team asked one question: did the programme work?

T
Task

My task was to measure the effect of the programme. The data had many villages, many months, and a lot of variability.

A
Action
  • I used mixed Poisson and negative binomial models.
  • I added a random effect for each village.
  • I automated the analysis in R.
  • I built Shiny dashboards for the team.
R
Result

The model estimated about 42 percent fewer malaria cases in the targeted villages.

Link to PK/PD: A random effect for each village is like a random effect for each patient in population PK.
30-second version: At Centre MURAZ, I evaluated a malaria programme. I used mixed models with a random effect per village. The result was about 42 percent fewer cases.

Les Vieilles Charrues · Data science intern

Brittany, FranceSummer 2025R · MCA · logistic regression
S
Situation

Les Vieilles Charrues is a big music festival in France. It receives about 7,500 volunteer applications. The team wanted to understand the selection.

T
Task

My task was to clean the data and explain the acceptance decisions.

A
Action
  • I cleaned the data.
  • I described the profiles with multiple correspondence analysis.
  • I fitted a logistic regression.
  • I checked the model with the Hosmer-Lemeshow test and the ROC curve.
R
Result

The model explains the main factors. The AUC was 0.68. So the model is useful to understand, not to decide automatically.

Link to PK/PD: I always check a model before I use it. PK/PD models also need checks, for example goodness-of-fit plots.
30-second version: For a music festival, I analysed 7,500 volunteer applications. I used a logistic regression and I validated it. I explained what the model can do and what it cannot do.

Academic project · Coordinated image sharing

ENSAI2025 to 2026Python · CLIP · UMAP · HDBSCAN
S
Situation

On social networks, some groups share the same images in a coordinated way. It is hard to see by hand.

T
Task

Our task was to detect these groups automatically in a large dataset.

A
Action
  • We used CLIP. It turns each image into a list of numbers.
  • We reduced the dimension with UMAP.
  • We found groups with HDBSCAN.
  • We tested the groups with permutation tests and an FDR correction.
R
Result

We built a validated pipeline on more than 217,000 posts.

Link to PK/PD: I know how to work with large data and many statistical tests, without false discoveries.
30-second version: In a school project, we detected coordinated image sharing. We used CLIP, UMAP and HDBSCAN on more than 217,000 posts, and we validated the results with statistical tests.

The four model families, in one sentence each

PKWhat the body does to the drug: absorption, distribution, elimination.
PDWhat the drug does to the body: the effect, for example on the tumour.
PopPK / NLMEA mixed model: an average patient plus the variability between patients.
TGITumour growth inhibition: how a tumour grows, and how the drug slows it.
PBPKA model of the body with real organs and blood flows.
Exposure-responseMore drug in the blood: more effect? More side effects?
